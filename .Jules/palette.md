## 2025-01-28 - [Add aria-labels to Quarto elements]
**Learning:** Quarto does not automatically generate `aria-label` attributes for icon-only elements like footers and inline HTML components, which makes them inaccessible for screen readers.
**Action:** Always manually define `aria-label` attributes for icon-only buttons, stand-alone inputs, and custom inline HTML blocks within Quarto contexts to ensure accessibility standards are met.
